How to Use This 3D Earth Map

Detailed workflow for map controls, LiDAR, imports, tools, and navigation.

1. Start with the map

  • Use the Map tab to switch between Topographic, Satellite, Nova Scotia 10K Imagery, the Nova Scotia LiDAR overlay, and the roads/place-names options.
  • Use the Roads & Place Names dropdown to place transparent roads and place names over any basemap or imagery.
  • Keep Terrain enabled for a true 3D surface.

2. Move around the scene

  • Drag to pan across the globe.
  • Mouse wheel zooms smoothly using the sensitivity slider in Settings → View Controls.
  • Use View Angle to tilt the camera and Auto-Rotate to keep the globe turning.

3. Use overlays

  • Select Nova Scotia Hillshade (LiDAR overlay) from the basemaps menu when you want terrain shading.
  • Use Roads & Place Names Overlay from the map type menu or Roads & Place Names → Roads & Place Names for a transparent overlay on top of Satellite or Nova Scotia 10K Imagery.
  • If either overlay looks faint, adjust the view angle and zoom closer.

4. Create your own places

  • Add Place Mark: type a name, click Add Place Mark, then click once on the map to drop a single point. Use this for custom pins, markers, and simple saved locations.
  • Add Path: click Add Path, then place points one by one to draw a line. Double-click or press Finalize to finish the path.
  • Add Polygon: click Add Polygon, then place points around an area. Double-click or press Finalize to close and save the shape.
  • Use Cancel if you want to stop the current creation mode and clear the draft points.

9. Keyboard shortcuts

  • Escape cancels create mode, closes geometry editing, and exits first-person mode.
  • Delete or Backspace removes the last draft point while creating a path or polygon.
  • Double-click finishes a path or polygon when you are in create mode.

5. Edit imported and created items

  • In My Places, open an item and choose the edit option to reshape paths and polygons.
  • Drag the white vertices to move them, click the ghost vertices to add new points, and press Delete or Backspace to remove selected vertices.
  • Imported items keep their original structure unless you save the edit, so always use Save when the shape is correct.
  • Created paths and polygons can also be edited the same way after they are added to My Places.

6. Import and export files

  • Go to File Import for supported file loading.
  • Use the type filters to show or hide categories after import.
  • Use the export buttons to save your current imported content back out as KML or KMZ.

7. Measure and inspect

  • Pick Coordinates reports the clicked point.
  • Measure Distance, Measure Area, and Elevation Profile let you build temporary measurement graphics and terrain cross-sections.
  • Use the copy button to quickly copy the currently selected latitude and longitude.

8. Keep the UI comfortable

  • Collapse the Earth Controls or Places panel from their headers when you want a cleaner view.
  • Settings are saved locally, so your preferred layout returns when the page reloads.
  • Use the map type controls to switch layers quickly without changing the rest of the layout.

9. Best-practice workflow

  • Pick the map style first, then turn on the LiDAR overlay if you need hillshade detail.
  • Adjust zoom sensitivity before fine work on dense areas.
  • Use the Places panel for editing, then save or export when you are done.
Tip: if something looks hidden or missing, check whether the relevant tab, layer toggle, or filter chip is currently turned off. Many features in this app are intentionally controlled from the panel rather than always shown on the map.
